# sprig-btree

A copy-on-write B+tree. It gives sprigdb ordered keys, range scans,
snapshots, and branches.

**Read first:** `src/lib.rs`.

**Depends on:** `sprig-pager`.
**Used by:** `sprig-exec`.

**Book chapters:** "The copy-on-write B+tree", "Snapshots for free",
"Branching, diffing and merging".
